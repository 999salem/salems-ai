S.A.L.E.M. BACKEND SETUP — CLOUDFLARE WORKERS

1. Create an OpenAI API key at https://platform.openai.com/api-keys
   IMPORTANT: never place that key in GitHub or in S.A.L.E.M.'s frontend.

2. Go to https://dash.cloudflare.com/ and create a Cloudflare Worker.
   Name suggestion: salem-ai-backend

3. Open the Worker's code editor and replace its code with the contents of salem-worker.js.
   Deploy the Worker.

4. In the Worker's Settings > Variables and Secrets, add:
   Type: Secret
   Name: OPENAI_API_KEY
   Value: your OpenAI API key
   Deploy/save the change.

5. Optional variable if you want to change the model:
   Name: OPENAI_MODEL
   Value: gpt-5.6-luna

6. Copy your Worker URL. It will look similar to:
   https://salem-ai-backend.YOUR-SUBDOMAIN.workers.dev

7. Open S.A.L.E.M. > Profile > Secure backend.
   Paste ONLY the base Worker URL above — do not add /api/chat.
   Tap Save Settings.

8. Test these:
   "What is 2+2?"
   "What's the latest Marvel news today?"

The frontend automatically calls:
YOUR_WORKER_URL/api/chat

Your API key remains encrypted as a Cloudflare Worker secret, not in the iPhone app.
